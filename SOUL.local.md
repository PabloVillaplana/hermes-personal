## Pitmio — what you must know

- **Read `CLAUDE.md` first, every session in pitmio.** Hermes auto-loads `AGENTS.md`, which in pitmio is generated by Laravel Boost and only holds framework rules (Pest, Pint, Inertia v3, Wayfinder). The project-specific guide — status, Sail commands, architecture, tenancy and data rules — is in `CLAUDE.md`. Product spec: `docs/PRODUCT.md` (Spanish); blueprint: `docs/ARCHITECTURE.md`.
- Stack: Laravel 13 / PHP 8.4, Inertia v3 + Vue 3 + TypeScript, Tailwind v4, shadcn-vue, Postgres, Redis, Horizon, S3 (RustFS), Pest, PHPStan level 8, Vite+ (`vp`).
- **Everything runs through Sail** (`./vendor/bin/sail …`, OrbStack). Checks: `sail composer lint`, `sail composer types`, `sail composer test`, `sail npm run test`, `sail npx vp check`, `sail npm run types:check`; `sail composer types:generate` after Data/enum changes (CI diffs it).
- Commits: Conventional Commits in English (`feat(ui): …`, `fix(admin): …`, `chore(seed): …`), branch `main`.
- **Real data lives only in the git-ignored `database/seeders/Local/`.** Never put real customer, workshop or vehicle data in tracked files.
- Non-negotiables from `CLAUDE.md`: modular monolith (`app/Domain/<Module>/`, modules talk only through Actions/Data/events), `BelongsToWorkshop` on every workshop-private model and cross-workshop tests, money as `decimal(19,4)` + currency (never floats, never computed by AI), no hard deletes (`voided_at`), append-only audit and stock ledgers, every UI string in both `lang/es.json` and `lang/en.json`, never edit Wayfinder-generated folders.
- Billing code (Paddle, Polar, manual SINPE) may be developed and tested with sandbox credentials only — the money rules in the core section apply in full.
- Laravel Boost MCP is configured for Claude Code (`.mcp.json`); when you delegate to Claude Code it can use it.
